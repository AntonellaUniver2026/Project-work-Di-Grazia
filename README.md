# Project Work – Piattaforma web museale MoMA

Prototipo di piattaforma web per la gestione delle visite, delle prenotazioni e del catalogo museale del Museum of Modern Art (MoMA).

## Obiettivo
Il progetto propone un sistema informatico per consultare le opere, visualizzare gli eventi e gestire le richieste di prenotazione delle visite.

## Tecnologie
- HTML per la struttura delle pagine
- CSS per la presentazione grafica
- JavaScript per le funzionalità lato client

## Organizzazione del repository
- docs: schemi e immagini illustrative del progetto
- static: file dell'interfaccia web
- tests: cartella destinata ai test

## Stato del progetto
Prototipo dimostrativo sviluppato nell'ambito del Project Work del corso di laurea L-31 – Informatica per le Aziende Digitali.

Il progetto ha finalità didattiche e non costituisce una piattaforma ufficiale del MoMA.
